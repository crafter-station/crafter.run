# Editorial social previews · October 6, 2026

The user requested that every OG image respond correctly and match the
redesign, with dynamic images where appropriate.

## Result

- A shared 1200×630 family: warm paper, generous margins, the original
  Crafter symbol, Crafter Display 0.200 / Text 0.309, pastel section palettes
  and the site's original illustrations.
- Home, OSS, Universe, Journal, events, Bounties, team, community, Ships,
  docs, contact, brand and metrics select their own content/art direction.
- Team profiles read the current roster and approved portraits. Team
  overview uses Railly → Ignacio → Liz → Edward. Alumni and hidden members
  never become current-profile cards.
- Articles use their translated title, summary, historical author names,
  publication date and matching Journal artwork.
- Bounties use canonical translated content, actual open/closed state,
  event date and original campaign artwork with a muted rendering.
  The original file is untouched.
- Public Crafter profiles and published Ships read the existing API.
  Ships now have page-specific canonical, OG and Twitter metadata.
- Documentation carries its actual page title and description.
- All metadata selects versioned URLs; OG and Twitter share the same image.
  Older title-only and handle-based `/og` links continue to work.
- Root PNG fallbacks are generated by the same renderer. The old asset
  script no longer produces the retired photo-background card.

## Files and maintenance

- `apps/web/lib/og.ts`: URL version, section selection, palettes and labels.
- `apps/web/lib/og-data.ts`: canonical data for dynamic cards.
- `apps/web/lib/og-assets.ts`: local fonts/art, image conversion and fallbacks.
- `apps/web/components/social-card.tsx`: the shared composition.
- `apps/web/app/og/route.tsx`: public Node image response.
- `apps/web/lib/seo.ts`: common OG/Twitter metadata.

Local Noto SC and JP Medium WOFFs preserve complete Unicode cmaps.
They load only when card text requires CJK. There are no request-time font
downloads. OFL files, hashes and reproduction notes live in `app/fonts`.
The added Display TTF matches the runtime WOFF2's version, outlines and
metrics exactly. No font design or team portrait was regenerated.

`next.config.mjs` explicitly traces the font and artwork files into `/og`.
External images are restricted to the known image hosts, have time/size
limits, and fall back to section artwork on failure. API lookups have a
five-second timeout. Cards cache for five minutes; unavailable data for one
minute. An open bounty's cache cannot extend beyond its deadline.

Regenerate SVG artwork after changing the site's original drawings:

```sh
bun run --cwd apps/web generate:social-art
```

Regenerate the two PNG fallbacks with the local web app running:

```sh
bun run --cwd apps/web generate:social-fallbacks
```

Set `OG_ORIGIN` to use another running app. This command doesn't touch icons,
portraits or original campaign artwork. Change `OG_VERSION` for a future
visual revision so shared pages advertise fresh image URLs.
