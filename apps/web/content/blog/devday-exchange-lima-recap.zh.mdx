2026 年 10 月 21 日，我们在利马圣马科斯国立大学（UNMSM）系统工程与信息学院（FISI）的礼堂举办了 DevDay Exchange Community: Lima。活动免费，全程使用西班牙语，属于 [Codex Community Events](https://luma.com/1iz8daqt) 日历的一部分，共有 86 人获批参加，其中大多数是学生。

当晚的所有照片都在 [DevDay Exchange Lima 相册](/events/devday-lima/gallery)。

## 分四个部分回顾 DevDay

<Figure src="/blog/devday-exchange-lima-recap/podium.webp" alt="Railly Hugo 站在讲台前，身后投影着活动封面" caption="Railly 为当晚活动开场。" size="1440x960" wide />

OpenAI 在主题演讲中一天内发布了大约二十项新功能。我们没有全部讲，而是挑出那些会改变我们构建方式的内容，由团队中的两个人分担整套幻灯片。

- **Railly Hugo** 以 Codex Originals 视频开场，介绍了 Crafter Station：社区、开源项目和 Makeables。
- **Edward Ramos** 讲了常驻智能体：Dots、ChatGPT Space、AppShots，以及 ChatGPT 为构建者带来的新功能，例如 plugin extensions 和 MCP events。
- **模型和 API** 由我们两人各讲一半：GPT-6.1 Sol、Ultrafast、Decisions API、Agents API 和 GPT Live。
- **Railly** 以 Codex 收尾：Codex Cloud、全新的 CLI 和代码审查。

## Codex 现场构建了一个应用

演示环节，我们在终端里用西班牙语让 Codex 为圣马科斯的 DevDay 做一个应用。我们一边讲解它在做什么，Codex 一边写出了一个用来给参与者抽奖的转盘。

每位参与者还拿到了一个 OpenAI API 额度兑换码，回家后可以继续构建。

## 下次我们会改进什么

我们原本安排了一个环节，让每位参与者用 Codex 做点东西，并用两分钟展示。但没来得及：开场比预期更久，而且会场没有足够的插座供那么多笔记本电脑使用。下次活动我们会：

- 缩短开场，并由专人把控时间。
- 安排有固定时长的 build & ship 环节，选择插座充足、网络稳定的场地。
- 在入口签到，弄清楚实际到场人数。
- 设计适合学生的形式：更多引导，更多动手。
