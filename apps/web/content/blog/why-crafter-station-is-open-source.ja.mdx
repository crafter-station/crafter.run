Crafter Station は、ペルーで何かをつくりたい人たちの WhatsApp グループから始まりました。いまではラテンアメリカ全体で 1,000 人以上のビルダーがいて、[github.com/crafter-station](https://github.com/crafter-station) には 219 の公開リポジトリがあります。私たちがつくるものは、ほとんどすべて読むことも、インストールすることも、フォークすることもできます。

オープンソースにすると会議で決めたことは一度もありません。最初のリポジトリからオープンにつくることが成果につながったので、そのまま続けてきました。この記事ではその理由を書きます。

## 公開したコードが履歴書になる

使われているリポジトリがあれば、どこの大学を出たかを聞かれることはありません。学位は授業に合格したことを示します。issue や pull request、ユーザーがいるリポジトリは、実際にシップできることを示します。

ペルーのビルダーにとって、これはとても大きな意味があります。リモートで採用する企業も、研究プログラムも、ファンドも、直接会う機会はありません。でも GitHub なら読めます。

## オープンな成果は思っていたより遠くまで届く

[petdex](https://github.com/crafter-station/petdex) は、Codex や Claude Code などのコーディングエージェント向けのアニメーションペットのギャラリーで、スターは 4,300 を超えています。shadcn/ui 向けのフルスタックブロック [elements](https://github.com/crafter-station/elements) は 550 以上、[text0](https://github.com/crafter-station/text0) は 450 以上です。

どれも宣伝キャンペーンはしていません。誰かが見つけて、インストールして、別の誰かに見せた。それだけです。クローズドなプロジェクトは自分で売り込む必要がありますが、オープンなプロジェクトは良いものであれば自分で広がっていきます。

## エージェントは読めるものしか勧めない

モデルに聞いてツールを見つける人が増えています。モデルが勧められるのは、読めるものだけです。だからこのサイトには `llms.txt` があり、すべての記事に markdown 版があり、README もエージェントが各リポジトリの役割と使い方を理解できるように書いています。

エージェントにとって、クローズドなコードは存在しないのと同じです。

## 公開すると学ぶのが速くなる

リポジトリが公開されていれば、誰でも issue を開いて問題を指摘できます。最初は少し居心地が悪いものです。それでも、上達するにはこれがいちばん速い方法です。会ったこともない人からの issue は、同じチームでのもう一回のレビューよりも多くを教えてくれます。

仕事を書いて公開することは、それを本当に理解することも求めます。README で説明できないなら、まだ終わっていないということです。

## オープンソースが意味しないこと

オープンソースだからといって、何も有料にしないわけでも、プロダクトがないわけでもありません。Crafter のプロジェクトのいくつかには有料版ができる予定で、それで問題ありません。オープンソースが意味するのは、仕事が見えることです。コードも、判断も、失敗も。

## 参加するには

- [github.com/crafter-station](https://github.com/crafter-station) のリポジトリを見て、すでに使っているものを選んでください。
- issue か pull request を開いてください。コントリビューターにはリポジトリごとにアクセス権を渡しています。
- [Discord](https://discord.gg/NRDWrGnxTU) のコミュニティに入って、何をつくっているか教えてください。

ペルーからでも、ラテンアメリカのどこからでも、つくっている人のための場所です。
