当日の写真はすべて[DevDay Exchange Limaのギャラリー](/events/devday-lima/gallery)で見られます。

## 4 つのパートで DevDay を振り返る

<Figure src="/blog/devday-exchange-lima-recap/podium.webp" alt="イベントのタイトルスライドの前で演台に立つ Railly Hugo" caption="夜の幕開けを担当する Railly。" size="1440x960" wide />

OpenAI は基調講演で、1 日に約 20 件の発表を行いました。すべては扱わず、私たちの作り方を変えるものを選び、チームの 2 人でスライドを分担しました。

- **Railly Hugo** は Codex Originals の動画でオープニングを飾り、Crafter Station について紹介しました。コミュニティ、オープンソースのプロジェクト、Makeables の話です。
- **Edward Ramos** は常時稼働のエージェントを担当しました。Dots、ChatGPT Space、AppShots、そして plugin extensions や MCP events など、ChatGPT でビルダー向けに新しくなった点です。
- **モデルと API** は 2 人で半分ずつ担当しました。GPT-6.1 Sol、Ultrafast、Decisions API、Agents API、GPT Live です。
- **Railly** が Codex で締めくくりました。Codex Cloud、新しい CLI、コードレビューです。

## Codex がライブでアプリを作った

デモでは、ターミナルからスペイン語で、サンマルコスの DevDay 用のアプリを Codex に頼みました。何をしているかを説明している間に、Codex は参加者向けの抽選ルーレットを書き上げました。

## 次回変えること

参加者一人ひとりが Codex で何かを作り、2 分で発表する時間を予定していました。しかし、そこまでたどり着けませんでした。オープニングが予定より長引き、会場には多くのノートパソコンをつなぐコンセントもありませんでした。次回は次のようにします。

- オープニングを短くし、時間管理の担当者を置く。
- コンセントと安定したインターネットがある会場で、時間を区切った build & ship セッションを行う。
- 入口でチェックインを行い、実際の来場者数を把握する。
- 学生向けに、よりガイド付きで手を動かせる形式にする。
