有很长一段时间，Crafter Station 首先是一个 WhatsApp 群，其次才是一个网站。一千多人在拉丁美洲各地构建，五十多场活动和黑客松，一百多个已经 ship 的产品，还有一堆真的有人安装的开源项目。这些几乎都没有写在任何可以贴链接的地方。

这个博客就是改变这件事的地方。我们从最简单的开始：一边做，一边告诉你我们在做什么。

## 你会在这里看到什么

两件事。

**我们做了什么。** 新工具、这个站点上的新页面、[hack0](/hackathon) 的新一届、走出实验室的产品。每篇文章都在工作完成的同一天发布，所以你看到的日期就是真实的日期。

**我们学到了什么。** 为什么选了这个而不是那个，什么地方出了问题，如果重来会怎么做。这部分几乎从来没人写下来，而它恰恰是我们刚开始时最想读到的部分。

文章上会有四个标签：工程、社区、产品和研究。它们是帮助阅读的标记，不是分类体系。这里没有可以走丢的分类页。

## 为什么公开写

社区里发生的大部分事情都发生在聊天里，而聊天不会累积。一段关于如何把自己的 CLI 发到 npm 的好解释，只帮到那天下午在线的十二个人，然后就被刷上去了。

把它写下来会逼我们理解得更透彻，也会留下一些下一个 builder 能找到的东西。如果它对你也有用，那就更好了。

我们不会每天发。我们会在有值得讲的事情时发。

## 怎么跟进

这是一个普通的博客，只是多开了几扇门：

- 给阅读器用的 [Atom 订阅](/blog/rss.xml)。
- 每篇文章的 markdown 版本：在任意文章 URL 后加 `.md`，或者用 `Accept: text/markdown` 请求。
- 全部文章的 [markdown 索引](/blog/sitemap.md)，给那些宁愿读列表也不愿爬站的智能体和模型。

如果你更想先试工具再读我们，[文档](/docs) 和 [开源目录](/oss) 就在那里。如果你在拉美构建，还没进社区，[来打个招呼](https://crafters.chat)。
