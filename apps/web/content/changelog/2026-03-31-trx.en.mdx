trx downloads, cleans and transcribes media from a URL or a local file. `trx init` installs whisper-cli, yt-dlp and ffmpeg, downloads a Whisper model and can install the agent skill for your coding tool.

It runs on macOS, Linux and Windows. Try `npx @crafter/trx@latest init` or open [trx.crafter.run](https://trx.crafter.run).
