sunat-cli lets an AI agent operate Peruvian tax procedures while a human supervises. It covers electronic invoices, SIRE, dispatch guides, the SOL mailbox, fee receipts and the REST APIs. The help output is the contract, so every command it lists exists in your installed version.

It ships frequent releases and runs on Node.

Install it with `npm install -g @crafter/sunat-cli`, or read the docs at [sunat-cli.crafter.ing](https://sunat-cli.crafter.ing).
