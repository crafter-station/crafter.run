wapi es una API REST de WhatsApp que corre en tu propio servidor. Vinculas un número, obtienes una API key y envías o recibes mensajes por HTTP, incluidos los grupos y chats personales a los que no llega la Cloud API de Meta. Es compatible a nivel de protocolo con WasenderAPI, así que los clientes existentes funcionan cambiando una sola URL base. Empieza en [wapi.crafter.run](https://wapi.crafter.run).

## Envía de todo, recibe todo

Un solo endpoint de envío cubre texto, imágenes, stickers, video y documentos. Los mensajes entrantes llegan a tu app como webhooks firmados, con reintentos y backoff. Grupos y contactos tienen sus propios endpoints.

## Un sandbox sin teléfono

Una sesión sandbox es un número falso en un WhatsApp falso que se vincula solo. Un contacto que no existe igual dispara un webhook real, así puedes construir contra wapi antes de conectarlo a un número de verdad.

## El riesgo, dicho claro

wapi maneja un cliente no oficial a través de Baileys, algo que va contra los términos de WhatsApp, así que los números usados así pueden ser restringidos o bloqueados. El README lo dice desde el inicio, y los proxies por sesión y un modo de envío pausado bajan el riesgo sin eliminarlo.

## Pruébalo

Descarga la CLI desde el [último release](https://github.com/crafter-station/wapi/releases) y luego:

```sh
wapi login
wapi sandbox create --use
wapi sessions connect
wapi send --to +51999888777 --text "hello"
```

La guía, la referencia de la API y el documento OpenAPI están enlazados desde [wapi.crafter.run](https://wapi.crafter.run).
