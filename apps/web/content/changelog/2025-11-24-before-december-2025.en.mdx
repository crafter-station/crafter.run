The smaller ships of the period, each with a live site, a published package or a release.

- [Retest](https://useretest.vercel.app): an A/B testing platform for quick product teams
- [krafter-ui](https://github.com/crafter-station/krafter-ui): the first Crafter Station UI library, published on npm
- [Gradual](https://trygradual.vercel.app/): a learning platform that breaks complex topics into small steps
- [GitHunter](https://githunter.dev): "Hunt the git", a GitHub exploration app with vector search
- [hipoteca-findr](https://hipoteca-ai.vercel.app): an AI tool to resolve mortgage uncertainty
- [ultra-deep-research](https://ultra-deep-research.vercel.app): a multi-LLM deep research pipeline
- [album0](https://album0.vercel.app): create and share public photo albums
- [pong0](https://pong0.vercel.app/): LLMs play tennis against each other
- [scrapi](https://scrapi.fast): turn any website into a deterministic API
