legalize-pe pone las leyes peruanas en un repositorio git. Cada una de sus 21,244 normas es un archivo Markdown con frontmatter YAML, y cada reforma es un commit con la fecha real en que se publicó, así que puedes ver cómo cambió una ley con `git log`. Es el corpus peruano de la federación [legalize.dev](https://legalize.dev). Recórrelo en [legalize-pe.crafter.ing](https://legalize-pe.crafter.ing).

## Cada reforma es un commit

La Constitución de 1993 es un solo archivo con toda su historia: el texto original y las 31 reformas aplicadas desde entonces, cada una como un commit. La página web muestra la metadata, un enlace a la fuente oficial y el endpoint que devuelve la línea de tiempo de commits.

## Normas nacionales y regionales

Las normas nacionales vigentes vienen del SPIJ, con fechas reales y sin OCR. El nivel regional cubre a los 25 gobiernos regionales y a Lima Metropolitana, armado desde gob.pe con el texto extraído de los PDF oficiales. Las normas sin texto legible quedan como metadata y un enlace a la fuente, nunca con texto inventado.

## Pruébalo

Clona el corpus y lee la historia de la Constitución:

```bash
git clone https://github.com/crafter-research/legalize-pe
cd legalize-pe
git log --oneline -- pe/CON-1993.md
```

O pídele la misma línea de tiempo a la API:

```bash
curl https://legalize-pe.crafter.ing/api/normas/pe-con-1993/history
```

El corpus vive en [legalize-pe](https://github.com/crafter-research/legalize-pe), y el código que lo genera, audita y sirve vive en [legalize-pe-engine](https://github.com/crafter-research/legalize-pe-engine). Es una copia comunitaria para investigación, no asesoría legal.
