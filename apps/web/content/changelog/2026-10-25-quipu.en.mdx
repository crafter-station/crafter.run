Type the name of your district and quipu tells you how many of every 100 soles it has already spent this year. The same figures are available in a CLI with `--json` and as an MCP server for AI agents.

It uses open MEF data for 2025 and 2026, needs no keys or accounts, and is unofficial.

Run `npx -y @lizethriveros/quipu mcp` to try the MCP server.
