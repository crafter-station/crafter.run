Petdex is the public gallery of animated pets for coding agents. The community submits, reviews and shows pets in the Codex sprite format, and you install one with a single command. It works with Codex, Claude Code, Gemini CLI and more. Browse more than 5,000 pets at [petdex.dev](https://petdex.dev).

## A gallery of pets

Each pet has its own page with a description, tags, collections and a state viewer for idle, running, waving, jumping, failed, waiting and review. Arrow keys browse the dex and the space bar shuffles.

<Figure src="/changelog/petdex/home.webp" alt="Petdex home with the install command and a row of featured pets" size="1280x800" caption="The home page, with the install command for the featured pet." />

## A CLI and a desktop app

The `petdex` CLI installs any pet with one command. Petdex Desktop floats the pet on your screen on macOS, Windows and Linux and animates it on every tool call your agent makes. Agents connect from its settings with one click.

## Try it

```bash
npx petdex install boba
```

Then get the desktop app at [petdex.dev/download](https://petdex.dev/download), or submit your own pet from [petdex.dev](https://petdex.dev). The CLI and the desktop app have shipped dozens of releases since May.
