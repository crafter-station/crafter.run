Petdex is a public gallery where the community submits, reviews and shows animated pets in the Codex sprite format. A web gallery, a command line and a desktop app work together, and you install a pet with one command.

It has had dozens of releases since May. Browse the gallery at [petdex.dev](https://petdex.dev).
