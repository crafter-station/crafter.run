Badge Studio opens on a draggable orbit of event badges. You can edit every layer, flip the badge, change its material and export it. With the `badgio` CLI and an agent skill, your coding agent can create a badge document for you.

Try it at [badge-studio.crafter.run](https://badge-studio.crafter.run) or run `npx badgio styles list`.
