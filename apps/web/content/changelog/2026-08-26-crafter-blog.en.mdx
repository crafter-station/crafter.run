The Crafter Station blog lives at [crafter.run/blog](https://crafter.run/en/blog). It is where the team writes about engineering and culture from people building in Latin America, for readers and for the agents they use.

<Clip src="/changelog/crafter-blog/read.mp4" poster="/changelog/crafter-blog/read.webp" size="1280x800" alt="Scrolling the blog index on crafter.run and opening a post" caption="The index filters by topic and searches in place." />

## Written in MDX, in more than one language

Posts are MDX files that ship in the same pull request as the work they describe. A post only needs the languages it is written in. When a translation is missing, the index links to the best available language instead of a page that does not exist.

## A Markdown twin of every post

Append `.md` to any post URL, or send `Accept: text/markdown`, and you get the same post as plain Markdown without the page chrome. Each language also has an Atom feed with full post bodies and a Markdown index of every post.

## Try it

Open [crafter.run/blog](https://crafter.run/en/blog), or read it the way an agent does:

```bash
curl https://crafter.run/en/blog/sitemap.md
curl https://crafter.run/en/blog/why-crafter-station-is-open-source.md
```

## What changed

- `/[lang]/blog` with topic filters and search, and a post page with authors linked to their team profiles
- An Atom feed per language at `/{locale}/blog/rss.xml`
- A Markdown twin of every post and a Markdown index at `/{locale}/blog/sitemap.md`
- `llms.txt` and `agents.md` list the blog
- The first posts were Hello, world and A website agents can read ([#75](https://github.com/crafter-station/crafter.run/pull/75))
