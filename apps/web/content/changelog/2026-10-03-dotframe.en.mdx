You write the game once in TypeScript and ship it to the web, iPhone, macOS, Windows and Discord. Every frame is deterministic, so an agent can play headless, rewind to any frame and find the bug your players hit.

Craft Ones and the Hot Reload game were built with it.

Install it with `npm i -g dotframe` and add the agent skill with `npx skills add crafter-games/dotframe`. Read more at [dotframe.crafter.games](https://dotframe.crafter.games).
