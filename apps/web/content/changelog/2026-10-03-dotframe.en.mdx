dotframe is a TypeScript game engine built so an AI agent can play the game it is helping you make. You write the game once and ship it to the web, iPhone, macOS, Windows and Discord. Every frame is deterministic, so your agent can play headless, look at any frame and find the bug before your players do. Read more at [dotframe.crafter.games](https://dotframe.crafter.games).

## No screen needed, until it wants one

The simulation is pure state and a fixed step. `dotframe sim` mashes inputs through 600 frames in a millisecond and prints the state as JSON. When the agent needs to see, `dotframe snap` renders that exact frame through the real WebGPU renderer as a PNG. Record a run once with `dotframe replay` and it becomes a test: every later change has to land on the same checksums.

## One codebase, five platforms

The web build uses WebGPU, with Canvas 2D on phones. iPhone gets a native app with no web view, macOS gets one binary on SDL3 and wgpu, Windows is cross-built from a Mac, and Discord runs it as an Activity in voice. There is no JavaScript engine in the native binaries.

## Try it

```bash
npm i -g dotframe
npx skills add crafter-games/dotframe
dotframe skills get core
```

Then ask your agent to start from the fighter, platformer or blank template with `dotframe new`.

## What it includes

- `sim`, `snap`, `replay` and `desync` to play, render and compare runs headless
- Rollback netplay with a relay you can deploy
- `build` and `deploy` for web, iOS, macOS, Windows and Discord, with `--dry-run` before anything external
- Skills bundled with each CLI version, from core to netplay and game design
- Craft Ones and the Hot Reload game were built with it
