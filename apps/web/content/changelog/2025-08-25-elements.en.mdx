Elements is a trusted shadcn registry of production-ready blocks for Next.js and TypeScript. Add a block like `npx shadcn@latest add @elements/clerk-sign-in` and customize the code that lands in your project. It includes theme-adaptive logos for tech companies and AI services.

Browse the blocks at [tryelements.dev](https://www.tryelements.dev/).
