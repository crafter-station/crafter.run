gh-ascii convierte tu avatar en arte ASCII y toma tus estadísticas (lenguajes, repos, estrellas, commits) de la API de GitHub. No necesita hosting ni API key, y el repo incluye un workflow de GitHub Actions que actualiza la tarjeta cada día.

Genera la tuya en [gh.crafter.run](https://gh.crafter.run).
