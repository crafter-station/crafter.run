Crafter UI está construida sobre shadcn Base UI con tokens compartidos para modo claro y oscuro. Haz clic en Use in my project y pega el prompt en tu agente de código, o usa el generador de estilos para elegir tu propia identidad, tokens y componentes y exportar un registro aparte.

La guía de diseño en [crafter.run/design.md](https://crafter.run/design.md) le da a tu agente las convenciones compartidas. Empieza en [ui.crafter.run](https://ui.crafter.run).
