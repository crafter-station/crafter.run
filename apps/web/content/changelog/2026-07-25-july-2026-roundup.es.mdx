Los ships más pequeños del período, cada uno con un sitio en vivo, un paquete publicado o un release.

- [Tab](https://tab.cueva.io/): autocompletado nativo para macOS con un overlay flotante de sugerencias
- [Limon](https://limon.lat): pega el enlace de Google Maps y obtén una web para tu restaurante
- [sv.cafe](https://www.sv.cafe/): un mapa comunitario de cafés de El Salvador calificados por Wi-Fi y enchufes
- [Sort](https://sort.uprizing.me): edita algoritmos de ordenamiento en JavaScript y mira cada operación
- [@crafter/sweep](https://github.com/crafter-station/sweep): encuentra y borra artefactos de desarrollo regenerables para recuperar espacio en disco
- [Backtick](https://backtick-red.vercel.app): convierte fragmentos de código en imágenes para compartir
- [bancolombia-cli](https://github.com/crafter-station/bancolombia-cli): gestiona cuentas de Bancolombia desde una terminal, una API REST o un servidor MCP
- [ubereats-cli](https://github.com/crafter-station/ubereats-cli): pide en Uber Eats desde una terminal, una API REST o un servidor MCP
- [whatsapp-cli](https://github.com/crafter-station/whatsapp-cli): una línea de comandos de WhatsApp, publicada como @crafter/whatsapp-cli
- [li-metrics](https://github.com/crafter-station/li-metrics): una CLI de solo lectura con analítica de posts de LinkedIn y salida JSON para agentes
