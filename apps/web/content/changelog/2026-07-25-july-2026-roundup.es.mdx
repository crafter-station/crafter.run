Julio de 2026 tuvo 10 ships más pequeños, todos de Station. Cuatro llegaron el 24 y el 25 de julio como líneas de comandos para servicios del día a día, con Bancolombia, Uber Eats, WhatsApp y analítica de LinkedIn, y bancolombia-cli es el ship con más estrellas del mes. Otros son para desarrolladores, como el autocompletado nativo para macOS de Tab y las imágenes de código de Backtick. Dos son para lugares locales, Limon para webs de restaurantes y sv.cafe para cafés de El Salvador.

sv.cafe es un mapa comunitario de cafés de El Salvador, calificados por su Wi-Fi y sus enchufes. Sort te deja editar algoritmos de ordenamiento en JavaScript y ver cada operación. Backtick convierte un fragmento de código en una imagen para compartir.

## Todo lo que salió

### Semana del 6 de julio

- **06 jul**: [Tab](https://github.com/crafter-station/tab): autocompletado nativo para macOS con un overlay flotante de sugerencias

### Semana del 13 de julio

- **15 jul**: [Limon](https://limon.lat): pega el enlace de Google Maps y obtén una web para tu restaurante
- **16 jul**: [sv.cafe](https://www.sv.cafe/): un mapa comunitario de cafés de El Salvador calificados por Wi-Fi y enchufes
- **19 jul**: [Sort](https://sort.uprizing.me): edita algoritmos de ordenamiento en JavaScript y mira cada operación

### Semana del 20 de julio

- **20 jul**: [@crafter/sweep](https://github.com/crafter-station/sweep): encuentra y borra artefactos de desarrollo regenerables para recuperar espacio en disco
- **22 jul**: [Backtick](https://backtick-red.vercel.app): convierte fragmentos de código en imágenes para compartir
- **24 jul**: [bancolombia-cli](https://github.com/crafter-station/bancolombia-cli): gestiona cuentas de Bancolombia desde una terminal, una API REST o un servidor MCP
- **24 jul**: [ubereats-cli](https://github.com/crafter-station/ubereats-cli): pide en Uber Eats desde una terminal, una API REST o un servidor MCP
- **24 jul**: [whatsapp-cli](https://github.com/crafter-station/whatsapp-cli): una línea de comandos de WhatsApp, publicada como @crafter/whatsapp-cli
- **25 jul**: [li-metrics](https://github.com/crafter-station/li-metrics): una CLI de solo lectura con analítica de posts de LinkedIn y salida JSON para agentes

## En números

- 10 ships, todos de Station
- 5 con sitio en vivo y 6 con un paquete publicado o un release (1 tiene ambos)
- 84 estrellas en GitHub en total (estrellas al 15 de noviembre de 2026)
