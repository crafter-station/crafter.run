Agosto de 2026 tuvo 11 ships más pequeños, todos de Station, y la mayoría corre en una terminal. Seis son líneas de comandos o SDKs, varios pensados para agentes, para cosas como la cartelera de Cinemark, catálogos de farmacias, la API del registrador Spaceship y rate limiting. Algunos trabajan en el Mac, como awake, que lo mantiene despierto con la tapa cerrada. Dos son para la comunidad, Crafter Tracker y Catch the Craft, un juego estilo osu!catch para The Next Craft.

Crafter Tracker es un mapa 8-bit en vivo de ships, cooking sessions y eventos de la comunidad. blaze te da una base de datos gestionada y gratis en 200 ms desde una API, un servidor MCP o un dashboard. Fitia CLI es una CLI y servidor MCP no oficiales para tu propia cuenta de Fitia.

## Todo lo que salió

### Semana del 1 de agosto

- **02 ago**: [Crafter Tracker](https://tracker.crafter.run): un mapa 8-bit en vivo de ships, cooking sessions y eventos de la comunidad

### Semana del 3 de agosto

- **05 ago**: [awake](https://github.com/crafter-station/awake): mantén tu Mac despierto con la tapa cerrada, seguro por defecto

### Semana del 10 de agosto

- **14 ago**: [butaca](https://github.com/crafter-station/butaca): cartelera y mapas de butacas de Cinemark Argentina desde la terminal
- **14 ago**: [osmo](https://github.com/crafter-station/osmo): una CLI nativa y estática para importar con seguridad el material de la DJI Osmo Nano
- **16 ago**: [airbridge](https://github.com/crafter-station/airbridge): comparte carpetas entre Windows y macOS por tu red local, sin nube ni cuentas

### Semana del 17 de agosto

- **19 ago**: [spaceship-cli](https://github.com/crafter-station/spaceship-cli): una CLI para agentes sobre la API del registrador Spaceship con las 50 operaciones
- **19 ago**: [blaze](https://blaze.crafter.run): bases de datos gestionadas y gratis en 200 ms desde una API, un servidor MCP o un dashboard

### Semana del 24 de agosto

- **27 ago**: [Catch the Craft](https://catch.crafter.run/): un juego estilo osu!catch para The Next Craft
- **30 ago**: [@crafter/limit](https://github.com/crafter-station/limit): un SDK de rate limiting para agentes con almacenamiento propio

### Semana del 31 de agosto

- **31 ago**: [farmacia](https://github.com/crafter-station/farmacia): una CLI para agentes sobre catálogos de farmacias, empezando por Farmacity en Argentina
- **31 ago**: [Fitia CLI](https://github.com/crafter-station/fitia-cli): una CLI y servidor MCP no oficiales para tu propia cuenta de Fitia
