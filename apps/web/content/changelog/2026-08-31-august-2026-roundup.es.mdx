Los ships más pequeños del período, cada uno con un sitio en vivo, un paquete publicado o un release.

- [Crafter Tracker](https://tracker.crafter.run): un mapa 8-bit en vivo de ships, cooking sessions y eventos de la comunidad
- [awake](https://github.com/crafter-station/awake): mantén tu Mac despierto con la tapa cerrada, seguro por defecto
- [butaca](https://github.com/crafter-station/butaca): cartelera y mapas de butacas de Cinemark Argentina desde la terminal
- [osmo](https://github.com/crafter-station/osmo): una CLI nativa y estática para importar con seguridad el material de la DJI Osmo Nano
- [airbridge](https://github.com/crafter-station/airbridge): comparte carpetas entre Windows y macOS por tu red local, sin nube ni cuentas
- [spaceship-cli](https://github.com/crafter-station/spaceship-cli): una CLI para agentes sobre la API del registrador Spaceship con las 50 operaciones
- [blaze](https://blaze.crafter.run): bases de datos gestionadas y gratis en 200 ms desde una API, un servidor MCP o un dashboard
- [Catch the Craft](https://catch.crafter.run/): un juego estilo osu!catch para The Next Craft
- [@crafter/limit](https://github.com/crafter-station/limit): un SDK de rate limiting para agentes con almacenamiento propio
- [farmacia](https://github.com/crafter-station/farmacia): una CLI para agentes sobre catálogos de farmacias, empezando por Farmacity en Argentina
- [Fitia CLI](https://github.com/crafter-station/fitia-cli): una CLI y servidor MCP no oficiales para tu propia cuenta de Fitia
