July 2026 had 10 smaller ships, all from Station. Four arrived on July 24 and 25 as command lines for everyday services, covering Bancolombia, Uber Eats, WhatsApp and LinkedIn analytics, and bancolombia-cli is the most starred ship of the month. Others are for developers, like Tab's native macOS autocomplete and Backtick's code images. Two are for local places, Limon for restaurant websites and sv.cafe for cafes in El Salvador.

sv.cafe is a community map of cafes in El Salvador, rated on their Wi-Fi and outlets. Sort lets you edit sorting algorithms in JavaScript and watch every operation run. Backtick turns a code snippet into an image you can share.

## Everything that shipped

### Week of Jul 6

- **06 Jul**: [Tab](https://github.com/crafter-station/tab): native macOS autocomplete with a floating suggestion overlay

### Week of Jul 13

- **15 Jul**: [Limon](https://limon.lat): paste a Google Maps link and get a website for your restaurant
- **16 Jul**: [sv.cafe](https://www.sv.cafe/): a community map of El Salvador's cafes rated on Wi-Fi and outlets
- **19 Jul**: [Sort](https://sort.uprizing.me): edit sorting algorithms in JavaScript and watch every operation

### Week of Jul 20

- **20 Jul**: [@crafter/sweep](https://github.com/crafter-station/sweep): find and delete regenerable dev artifacts to reclaim disk space
- **22 Jul**: [Backtick](https://backtick-red.vercel.app): turn code snippets into shareable images
- **24 Jul**: [bancolombia-cli](https://github.com/crafter-station/bancolombia-cli): manage Bancolombia accounts from a terminal, a REST API or an MCP server
- **24 Jul**: [ubereats-cli](https://github.com/crafter-station/ubereats-cli): order from Uber Eats through a terminal, a REST API or an MCP server
- **24 Jul**: [whatsapp-cli](https://github.com/crafter-station/whatsapp-cli): a WhatsApp command line, published as @crafter/whatsapp-cli
- **25 Jul**: [li-metrics](https://github.com/crafter-station/li-metrics): a read-only LinkedIn post analytics CLI with agent-first JSON output

## By the numbers

- 10 ships, all from Station
- 5 with a live site and 6 with a published package or release (1 has both)
- 84 GitHub stars in total (stars as of Nov 15, 2026)
