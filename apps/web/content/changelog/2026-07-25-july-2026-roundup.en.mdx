The smaller ships of the period, each with a live site, a published package or a release.

- [Tab](https://github.com/crafter-station/tab): native macOS autocomplete with a floating suggestion overlay
- [Limon](https://limon.lat): paste a Google Maps link and get a website for your restaurant
- [sv.cafe](https://www.sv.cafe/): a community map of El Salvador's cafes rated on Wi-Fi and outlets
- [Sort](https://sort.uprizing.me): edit sorting algorithms in JavaScript and watch every operation
- [@crafter/sweep](https://github.com/crafter-station/sweep): find and delete regenerable dev artifacts to reclaim disk space
- [Backtick](https://backtick-red.vercel.app): turn code snippets into shareable images
- [bancolombia-cli](https://github.com/crafter-station/bancolombia-cli): manage Bancolombia accounts from a terminal, a REST API or an MCP server
- [ubereats-cli](https://github.com/crafter-station/ubereats-cli): order from Uber Eats through a terminal, a REST API or an MCP server
- [whatsapp-cli](https://github.com/crafter-station/whatsapp-cli): a WhatsApp command line, published as @crafter/whatsapp-cli
- [li-metrics](https://github.com/crafter-station/li-metrics): a read-only LinkedIn post analytics CLI with agent-first JSON output
