Muelle replaces the Windows taskbar with a customizable dock and an optional macOS-style menu bar. It has smooth magnification, live window previews and an optional Genie minimize effect, and it shows usage limits for Claude Code, Codex, GitHub Copilot, Cursor and more.

It is free. Download it at [muellee.vercel.app](https://muellee.vercel.app).
