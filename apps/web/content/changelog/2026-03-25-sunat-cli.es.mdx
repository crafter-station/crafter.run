sunat-cli permite que un agente de IA opere trámites tributarios peruanos mientras una persona supervisa. Cubre comprobantes electrónicos, SIRE, guías de remisión, el Buzón SOL, recibos por honorarios y las APIs REST. La salida de `--help` es el contrato, así que cada comando que lista existe en tu versión instalada.

Publica versiones con frecuencia y corre sobre Node.

Instálalo con `npm install -g @crafter/sunat-cli` o lee la documentación en [sunat-cli.crafter.ing](https://sunat-cli.crafter.ing).
