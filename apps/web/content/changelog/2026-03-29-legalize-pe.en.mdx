legalize-pe is the Peruvian corpus of the legalize.dev federation. Each law is a file with YAML frontmatter, and each reform is a commit, so you can read how a norm changed with `git log`.

The corpus lives in one repository and the code that generates, audits and serves it lives in legalize-pe-engine.

Browse it at [legalize-pe.crafter.ing](https://legalize-pe.crafter.ing).
