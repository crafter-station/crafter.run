Los ships más pequeños del período, cada uno con un sitio en vivo, un paquete publicado o un release.

- [Retest](https://useretest.vercel.app): una plataforma de A/B testing para equipos de producto ágiles
- [krafter-ui](https://github.com/crafter-station/krafter-ui): la primera librería de UI de Crafter Station, publicada en npm
- [Gradual](https://trygradual.vercel.app/): una plataforma de aprendizaje que divide temas complejos en pasos pequeños
- [GitHunter](https://githunter.dev): "Hunt the git", una app para explorar GitHub con búsqueda vectorial
- [hipoteca-findr](https://hipoteca-ai.vercel.app): una herramienta de IA para resolver la incertidumbre de las hipotecas
- [ultra-deep-research](https://ultra-deep-research.vercel.app): un pipeline de investigación profunda con varios LLMs
- [album0](https://album0.vercel.app): crea y comparte álbumes de fotos públicos
- [pong0](https://pong0.vercel.app/): LLMs que juegan tenis entre ellos
- [scrapi](https://scrapi.fast): convierte cualquier sitio web en una API determinista
