Este resumen reúne los 9 ships más pequeños de los dos años anteriores a diciembre de 2025, desde Retest en diciembre de 2023 hasta scrapi en noviembre de 2025. Los 9 salieron de Station. La mayoría son herramientas para desarrolladores, como una plataforma de A/B testing, la primera librería de UI de Crafter Station y una forma de convertir sitios web en APIs. Varios otros trabajan con modelos de lenguaje, desde un pipeline de investigación con varios LLMs hasta pong0, donde los modelos juegan tenis entre ellos. GitHunter, una app para explorar GitHub con búsqueda vectorial, es el ship con más estrellas del grupo.

scrapi, el ship más reciente de este resumen, convierte cualquier sitio web en una API determinista. album0 te permite crear un álbum de fotos público y compartirlo con un enlace. ultra-deep-research corre un pipeline de investigación profunda con varios modelos de lenguaje.

## Todo lo que salió

### 2023

- **04 dic 2023**: [Retest](https://useretest.vercel.app): una plataforma de A/B testing para equipos de producto ágiles

### 2024

- **31 ago 2024**: [krafter-ui](https://github.com/crafter-station/krafter-ui): la primera librería de UI de Crafter Station, publicada en npm

### 2025

- **06 feb 2025**: [Gradual](https://trygradual.vercel.app/): una plataforma de aprendizaje que divide temas complejos en pasos pequeños
- **01 may 2025**: [GitHunter](https://githunter.dev): "Hunt the git", una app para explorar GitHub con búsqueda vectorial
- **07 jun 2025**: [hipoteca-findr](https://hipoteca-ai.vercel.app): una herramienta de IA para resolver la incertidumbre de las hipotecas
- **19 jul 2025**: [ultra-deep-research](https://ultra-deep-research.vercel.app): un pipeline de investigación profunda con varios LLMs
- **25 ago 2025**: [album0](https://album0.vercel.app): crea y comparte álbumes de fotos públicos
- **14 sep 2025**: [pong0](https://pong0.vercel.app/): LLMs que juegan tenis entre ellos
- **24 nov 2025**: [scrapi](https://scrapi.fast): convierte cualquier sitio web en una API determinista

## En números

- 9 ships, todos de Station
- 8 con sitio en vivo y 1 con un paquete publicado o un release
- 47 estrellas en GitHub en total (estrellas al 15 de noviembre de 2026)
