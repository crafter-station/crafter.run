CircuitKit le da a tu agente de código una forma de dibujar circuitos. Describes módulos y conexiones, y genera en local un diagrama de bloques, un diagrama de cableado o un esquemático como SVG o PNG limpio. Es para makers y equipos de hardware que quieren diagramas que vivan junto a su código. Prueba el playground en [circuitkit.crafter.ing](https://circuitkit.crafter.ing).

## Una fuente, tres diagramas

Un archivo `.ck` nombra los módulos, sus puertos y los buses que los unen. CircuitKit dibuja esa misma fuente como bloques, cableado o esquemático modular, sin coordenadas que mantener. Un bloque `presentation` opcional agrega secciones, resaltados y un flujo de señal ilustrativo para explicar el circuito.

## Hecho para tu agente

Pega el prompt de configuración o instala la skill y pídele el diagrama a tu agente. El paquete tipado, los componentes de React, la CLI y la skill comparten un mismo documento JSON, y todo se genera en local, sin cuenta ni backend.

## Pruébalo

```bash
npx skills add crafter-lab/circuitkit --skill circuitkit
npm install circuitkit
npx circuitkit grammar --json
```

O abre el [playground](https://circuitkit.crafter.ing/editor?mode=circuitkit) en tu navegador.

## Qué incluye

- Un lenguaje de texto compacto en archivos `.ck` o bloques de Markdown, con soporte para JSON
- Los comandos `render`, `format` y `expand` en la CLI
- Componentes de React y una librería tipada
- Un servidor MCP, compilado desde el código fuente, que muestra los circuitos como imágenes en la conversación
- Licencia Apache-2.0. Es una herramienta de dibujo, no un simulador.
