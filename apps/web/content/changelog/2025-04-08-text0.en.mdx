text0 is a text editor with autocomplete that reads the references you give it. It is for developers who write docs, notes and updates and want suggestions grounded in their own material. Try it at [text0.dev](https://text0.dev).

<Figure src="/changelog/text0/autocomplete.webp" alt="text0 editor suggesting the rest of a sentence in gray, with saved memories in the side panel" size="1280x838" caption="The gray text is the suggestion, drawn from the saved memories on the right." />

## Autocomplete that knows your context

As you type, text0 proposes the next words in gray. It draws on the memories and references you add in the assistant panel, so a suggestion can cite a number from a pricing page you saved instead of guessing.

## Your documents and memories in one place

The home screen lists your documents and memories, with search and quick actions to start a new one. GitHub, Linear and Notion integrations bring outside context in, and you can chat with your content, dictate by voice or switch to zen mode.

<Figure src="/changelog/text0/home.webp" alt="text0 home screen with recent documents, new document, new memory and search actions" size="1280x832" caption="Documents, memories and integrations share one sidebar." />

## Built at the Next.js Hackathon

text0 was built for the first global Next.js Hackathon, run by Vercel in April 2025, and was announced among its winners.

## Try it

Open [text0.dev](https://text0.dev), or run it locally:

```bash
git clone https://github.com/crafter-station/text0.git
cd text0
bun install
bun dev
```

## What it includes

- AI autocomplete that uses the references you provide
- Chat with your content
- GitHub, Linear and Notion integrations
- Voice input and output
- Zen mode
- Open source on [GitHub](https://github.com/crafter-station/text0)
