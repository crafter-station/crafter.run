Lo que construye la comunidad ahora tiene su lugar en crafter.run. Creas un Ship una vez, pegando el link de tu repo o desde tu terminal, y cada update queda en tu perfil. Los Ships recientes aparecen en la home, en [crafter.run](https://crafter.run/es).

## Publica desde un link o desde tu agente

En [crafter.run/ships/new](https://crafter.run/es/ships/new) publicas en tres pasos. Pegas el link de tu repo o tu sitio y el nombre, la frase corta y la descripción se llenan solos. Revisas los campos y ves cómo quedará tu Ship antes de publicarlo. Si prefieres la terminal, la página trae un prompt para copiarle a Claude Code, Codex o cualquier agente: arma el borrador con el CLI y espera tu OK antes de publicar.

<Figure src="/changelog/ships-for-everyone/new-ship.webp" alt="Paso 3 de 3 del nuevo Ship, con la vista previa de la card y el aviso de que se revisa solo el primer Ship" size="800x1060" caption="El último paso muestra la card tal como se verá en la lista." />

El CLI trae sus propias skills, siempre de la versión que tienes instalada. Para que tu agente las encuentre, instala una sola: `npx skills add crafter-station/crafter.run --skill crafter`.

<Clip src="/changelog/ships-for-everyone/terminal.mp4" poster="/changelog/ships-for-everyone/terminal.webp" size="1280x800" alt="Terminal con crafter --version 0.7.2, crafter skills list mostrando changelog y ship, y el inicio de crafter skills get ship" caption="crafter skills list muestra lo que sabe hacer tu versión del CLI." />

## Tus releases se vuelven updates

Agrega el topic `crafter-ship` a un repo público en GitHub y cada release nueva se publica como update de su Ship, sin que hagas nada. Funciona cuando tu cuenta de crafter.run tiene vinculado el GitHub dueño o contribuidor del repo. El dueño del Ship también puede traer sus releases al instante con "Sync releases".

## Tu perfil, tu espacio

Crear tu perfil toma cuatro pasos, y solo el handle y el nombre son obligatorios. Si entras con GitHub, tu nombre, tu foto, tu bio y tus links ya vienen llenos. Para tu ciudad basta un buscador, con Perú, Argentina, México, Colombia, Chile y España primero. Tu agente también puede llenarlo con `crafter profile update`.

## Revisamos solo el primero

El primer Ship de cada persona lo revisa el equipo antes de publicarse, y solo miramos spam y abuso, no la calidad. Desde ahí publicas directo. Core y Crew publican directo desde el inicio.

## Pruébalo

Entra en [crafter.run/es/sign-in](https://crafter.run/es/sign-in) y publica tu primer Ship en [crafter.run/es/ships/new](https://crafter.run/es/ships/new). Desde la terminal:

```sh
npm i -g @crafter/cli
crafter skills get ship
crafter profile get
```

## Qué cambió

- El primer Ship de cada miembro pasa por revisión, la home muestra los Ships de la comunidad y cada Ship se comparte en WhatsApp ([#193](https://github.com/crafter-station/crafter.run/pull/193)).
- El CLI sirve sus propias skills con `crafter skills list` y `crafter skills get` ([#194](https://github.com/crafter-station/crafter.run/pull/194)).
- Ships ordenados por actividad, feed Atom y línea de tiempo en el perfil ([#195](https://github.com/crafter-station/crafter.run/pull/195)).
- Una sola skill `crafter` para instalar y un prompt para tu agente en la página de nuevo Ship ([#198](https://github.com/crafter-station/crafter.run/pull/198)).
- Las releases de GitHub se vuelven updates con el topic `crafter-ship` ([#201](https://github.com/crafter-station/crafter.run/pull/201)).
- Entrar visible en cada página y una página de acceso nueva ([#202](https://github.com/crafter-station/crafter.run/pull/202)).
- `crafter profile get` y `crafter profile update` para leer y editar tu perfil desde la terminal ([#207](https://github.com/crafter-station/crafter.run/pull/207)).
- Perfil en cuatro pasos con datos de GitHub y buscador de ciudades ([#209](https://github.com/crafter-station/crafter.run/pull/209)).
- Nuevo Ship en tres pasos, en los cinco idiomas ([#213](https://github.com/crafter-station/crafter.run/pull/213)).
- Vitrina de Ships con destacado, pulso y muro de makers ([#214](https://github.com/crafter-station/crafter.run/pull/214)), y destacado elegido por el equipo ([#220](https://github.com/crafter-station/crafter.run/pull/220)).
- Página de cada Ship rediseñada, con su color, una historia con videos y el autor al final ([#217](https://github.com/crafter-station/crafter.run/pull/217), [#221](https://github.com/crafter-station/crafter.run/pull/221), [#222](https://github.com/crafter-station/crafter.run/pull/222)).
- Las imágenes grandes se achican antes de subir para que no fallen ([#218](https://github.com/crafter-station/crafter.run/pull/218)).
