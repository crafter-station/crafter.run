August 2026 had 11 smaller ships, all from Station, and most of them run in a terminal. Six are command lines or SDKs, several built agent-first, for things like Cinemark showtimes, pharmacy catalogs, the Spaceship registrar API and rate limiting. A few work on the Mac, such as awake, which keeps it awake with the lid closed. Two are for the community, Crafter Tracker and Catch the Craft, an osu!catch style game for The Next Craft.

Crafter Tracker is a live 8-bit map of community ships, cooking sessions and events. blaze gives you a free managed database in 200ms from an API, an MCP server or a dashboard. Fitia CLI is an unofficial CLI and MCP server for your own Fitia account.

## Everything that shipped

### Week of Aug 1

- **02 Aug**: [Crafter Tracker](https://tracker.crafter.run): a live 8-bit map of community ships, cooking sessions and events

### Week of Aug 3

- **05 Aug**: [awake](https://github.com/crafter-station/awake): keep your Mac awake with the lid closed, safe by default

### Week of Aug 10

- **14 Aug**: [butaca](https://github.com/crafter-station/butaca): Cinemark Argentina showtimes and seat maps from the terminal
- **14 Aug**: [osmo](https://github.com/crafter-station/osmo): a static native CLI to import DJI Osmo Nano footage safely
- **16 Aug**: [airbridge](https://github.com/crafter-station/airbridge): share folders between Windows and macOS over your LAN, with no cloud or accounts

### Week of Aug 17

- **19 Aug**: [spaceship-cli](https://github.com/crafter-station/spaceship-cli): an agent-first CLI for the Spaceship registrar API with all 50 operations
- **19 Aug**: [blaze](https://blaze.crafter.run): free managed databases in 200ms from an API, an MCP server or a dashboard

### Week of Aug 24

- **27 Aug**: [Catch the Craft](https://catch.crafter.run/): an osu!catch style game for The Next Craft
- **30 Aug**: [@crafter/limit](https://github.com/crafter-station/limit): an agent-first rate limiting SDK with bring-your-own storage

### Week of Aug 31

- **31 Aug**: [farmacia](https://github.com/crafter-station/farmacia): an agent-first CLI for pharmacy catalogs, starting with Farmacity in Argentina
- **31 Aug**: [Fitia CLI](https://github.com/crafter-station/fitia-cli): an unofficial CLI and MCP server for your own Fitia account
