The smaller ships of the period, each with a live site, a published package or a release.

- [Crafter Tracker](https://tracker.crafter.run): a live 8-bit map of community ships, cooking sessions and events
- [awake](https://github.com/crafter-station/awake): keep your Mac awake with the lid closed, safe by default
- [butaca](https://github.com/crafter-station/butaca): Cinemark Argentina showtimes and seat maps from the terminal
- [osmo](https://github.com/crafter-station/osmo): a static native CLI to import DJI Osmo Nano footage safely
- [airbridge](https://github.com/crafter-station/airbridge): share folders between Windows and macOS over your LAN, with no cloud or accounts
- [spaceship-cli](https://github.com/crafter-station/spaceship-cli): an agent-first CLI for the Spaceship registrar API with all 50 operations
- [blaze](https://blaze.crafter.run): free managed databases in 200ms from an API, an MCP server or a dashboard
- [Catch the Craft](https://catch.crafter.run/): an osu!catch style game for The Next Craft
- [@crafter/limit](https://github.com/crafter-station/limit): an agent-first rate limiting SDK with bring-your-own storage
- [farmacia](https://github.com/crafter-station/farmacia): an agent-first CLI for pharmacy catalogs, starting with Farmacity in Argentina
- [Fitia CLI](https://github.com/crafter-station/fitia-cli): an unofficial CLI and MCP server for your own Fitia account
