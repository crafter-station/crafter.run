You describe modules and connections, and CircuitKit renders a block diagram, a wiring diagram or a schematic locally. One JSON document is shared by the library, the React components, the CLI and the agent skill.

Install `circuitkit` from npm or try the playground at [circuitkit.crafter.ing](https://circuitkit.crafter.ing).
