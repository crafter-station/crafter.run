Crafter UI is built on shadcn Base UI with shared light and dark tokens. Click Use in my project and paste the prompt into your coding agent, or use the style generator to choose your own identity, tokens and components and export a separate registry.

The design guide at [crafter.run/design.md](https://crafter.run/design.md) gives your agent the shared conventions. Start at [ui.crafter.run](https://ui.crafter.run).
