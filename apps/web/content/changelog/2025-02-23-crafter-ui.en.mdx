Crafter UI is a component library for teams who want shadcn defaults with their own identity on top. It is built on shadcn Base UI, with shared light and dark tokens and a layer of Crafter atoms, molecules and organisms. Start at [ui.crafter.run](https://ui.crafter.run).

<Clip src="/changelog/crafter-ui/showcase.mp4" poster="/changelog/crafter-ui/showcase.webp" size="1280x800" alt="Clicking through the live examples on the Crafter UI home page, typing a project name and creating a project" caption="Every example on the home page is a working component." />

## Browse every component

The components page lists the shadcn primitives next to the Crafter atoms, molecules and organisms. Each one opens a live example with its source, and any page can be copied as Markdown for your agent.

<Figure src="/changelog/crafter-ui/components.webp" alt="Crafter UI components page with the shadcn primitives and Crafter atoms in the sidebar" size="1280x800" caption="Primitives first, Crafter compositions when the same pattern keeps showing up." />

## Make the library yours

The style generator lets you name your library, tune the shared theme and pick the components you need. It exports a separate registry, so your team installs your version, with your tokens.

<Figure src="/changelog/crafter-ui/generator.webp" alt="Crafter UI style generator with a library name field and a live preview card" size="1280x800" caption="Valid changes are saved in your browser until you export." />

## Try it

Open [ui.crafter.run](https://ui.crafter.run), click Use in my project and paste the prompt into your coding agent. The design guide at [crafter.run/design.md](https://crafter.run/design.md) gives your agent the shared component and token conventions for future UI work.
