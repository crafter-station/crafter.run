Escribe el nombre de tu distrito y quipu te dice cuántos de cada 100 soles ya gastó este año. Las mismas cifras están en una CLI con `--json` y como servidor MCP para agentes de IA.

Usa datos abiertos del MEF de 2025 y 2026, no necesita claves ni cuentas y no es oficial.

Corre `npx -y @lizethriveros/quipu mcp` para probar el servidor MCP.
