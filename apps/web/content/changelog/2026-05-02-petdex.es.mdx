Petdex es la galería pública de mascotas animadas para agentes de código. La comunidad envía, revisa y muestra mascotas en el formato de sprites de Codex, y cada una se instala con un solo comando. Funciona con Codex, Claude Code, Gemini CLI y más. Recorre más de 5,000 mascotas en [petdex.dev](https://petdex.dev).

## Una galería de mascotas

Cada mascota tiene su página con descripción, etiquetas, colecciones y un visor de estados: reposo, corriendo, saludando, saltando, error, esperando y revisión. Las flechas recorren el dex y la barra espaciadora elige una al azar.

<Figure src="/changelog/petdex/home.webp" alt="Inicio de Petdex con el comando de instalación y una fila de mascotas destacadas" size="1280x800" caption="La portada, con el comando de instalación de la mascota destacada." />

## Un CLI y una app de escritorio

El CLI `petdex` instala cualquier mascota con un comando. Petdex Desktop deja la mascota flotando en tu pantalla en macOS, Windows y Linux, y la anima con cada llamada a herramientas de tu agente. Los agentes se conectan desde su configuración con un clic.

## Pruébalo

```bash
npx petdex install boba
```

Después descarga la app de escritorio en [petdex.dev/download](https://petdex.dev/download), o envía tu propia mascota desde [petdex.dev](https://petdex.dev). El CLI y la app de escritorio llevan decenas de releases desde mayo.
